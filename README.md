# Accounts Service

![Build Status](https://github.com/Ozodbek-best/accounts-service/actions/workflows/ci-build.yaml/badge.svg)

Accounts Service is a RESTful microservice for managing customer accounts. It supports creating, listing, reading, updating and deleting accounts.

## Features
- CRUD operations for accounts
- Continuous integration with GitHub Actions
- Security headers (Talisman) and CORS policies
- Containerized with Docker and deployed to Kubernetes
- Automated delivery with a Tekton CD pipeline
